# Belajar AI Agent

Contoh awal chatbot AI sederhana untuk belajar alur dasar menerima pesan, memprosesnya, dan menampilkan balasan. Kode ini memakai fungsi balasan contoh, belum terhubung ke model AI sungguhan.

## Mulai

1. Pastikan Python 3.10 atau lebih baru sudah terpasang.
2. Instal dependensi dengan `pip install -r requirements.txt`.
3. Jalankan `python main.py`.

Lihat komentar dan TODO di `main.py` untuk langkah belajar berikutnya.
